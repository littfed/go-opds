# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of `go-opds` seriously. If you discover a security vulnerability, please do not report it through public GitHub issues.

Instead, please report security vulnerabilities via:
- **GitHub Private Vulnerability Reporting** (preferred, available on the repository's Security tab).
- Or by emailing the project maintainers directly.

### What to include in your report:
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue or a minimal proof of concept.
- Affected versions and configurations.

### Response Timeline
- You will receive an acknowledgment within 48 hours.
- A remediation plan and fix will be prepared in a private advisory before public release.
- We will coordinate public disclosure and release notes with you.
